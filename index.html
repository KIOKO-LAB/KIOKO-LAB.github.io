Path Finder: Memory Puzzle

길을 3초간 보여주고 사라져요. 기억만으로 그대로 따라가세요. 기억력을 키우는 메모리 두뇌 게임이에요.

The path shows for 3 seconds, then vanishes. Trace it back from memory alone — a memory puzzle & brain training game.

道が3秒間だけ表示されて消えます。記憶だけでなぞりましょう。記憶力を鍛える記憶パズル・脳トレゲームです。

MemoTap — Instant Memory Test

"1"을 누르는 순간 숫자가 사라져요. 기억만으로 순서대로 탭하세요. 침팬지 평균은 레벨 9 — 당신은 몇 레벨?

Tap "1" and every number hides. Tap them in order from memory alone. Chimps average level 9 — can you beat them?

「1」をタップした瞬間、数字が隠れます。記憶だけで順番にタップ。チンパンジーの平均はレベル9 — あなたは?

1.0.1 신규 — 플레이 모드 3종. 클래식(침팬지 비교) · 룰 챌린지(역순·홀짝·양끝) · 섬광(0.21초, 아유무 실험 재현). 외운 순서와 눌러야 하는 순서가 달라져요. New in 1.0.1 — three play modes. Classic (the chimp comparison), Rule Challenge (reverse, odd→even, both ends), and Flash (0.21s, recreating the Ayumu experiment). What you memorize is no longer what you tap. 1.0.1 新機能 — プレイモード3種。クラシック(チンパンジー比較)・ルールチャレンジ(逆順・奇数偶数・両端)・閃光(0.21秒、アユム実験の再現)。覚えた順と押す順が変わります。
